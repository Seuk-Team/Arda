# 점수 기준 (각 0~100)

| 갈래 | 100 에 가까울수록 | 0 에 가까울수록 |
|---|---|---|
| requirements_score | 필수 요건 항목을 **전부, 요구 수준 이상으로** 충족 | 필수 요건과 무관하거나 판단 근거가 없음 |
| preferred_score | 우대 항목 여럿을 실제 경험으로 보임 | 우대 항목 해당 없음 (우대가 비어 있으면 50) |
| culture_score | 인재상 "함께 일하고 싶은 사람" 의 흔적이 원문 문장에 있음 | "잘 안 맞는 사람" 의 신호가 명시적으로 있음. 근거가 전혀 없으면 50 |

# 채점 순서

1. 필수 요건을 항목별로 나누고, 항목마다 원문(기술 스택·경력·자기소개)에서 근거를 찾는다. 요건 하나라도 원문에서 확인되지 않으면 그 항목은 미충족이다.
2. 우대 항목도 같은 방식으로 하나씩 대조한다.
3. 인재상 문장과 원문 자기소개를 대조한다.
4. 대조 결과로 점수를 정한다. 같은 원문에는 같은 점수가 나와야 한다 — 문장 표현이 아니라 충족한 항목 수와 수준으로 정한다.

# 지켜야 할 것

1. 원문에 **있는 사실만** 근거로 쓴다. 추론하지 않는다. 근거가 없으면 점수를 50 근처에 두고 concerns 에 "확인 필요" 로 적는다.
2. "합격", "부적합", "채용을 권한다" 같은 결론을 쓰지 않는다.
3. 요건과 **대조하는 문장**을 쓴다 — "React 2년 요건에 4년 실서비스" 는 대조, "React 보유" 는 나열이다.
4. 경력 연차 요건(예: "2년 이상 6년 이하")은 상한 초과도 concerns 로 적는다.
5. 영어 원문도 같은 기준으로 채점하고 출력은 한국어 평서체로 쓴다.
6. 주민등록번호, 주소, 연락처, 생년월일, 가족사항, 성별, 나이, 출신 지역, 혼인 여부를 점수 근거나 출력에 쓰지 않는다.
