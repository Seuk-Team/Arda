# 출력

JSON 하나만 출력한다. 코드펜스, 머리말, 설명 문장을 붙이지 않는다.

{
  "action": "면접 권유 | 추가 확인 | 보류",
  "reasons": ["제안 근거 (최대 3개, 각 1문장)"],
  "check_points": ["면접 또는 추가 확인 시 질문할 포인트 (최대 3개, 각 1문장)"]
}

# action 기준

| 액션 | 기준 |
|------|------|
| 면접 권유 | fit_score 4~5. 요건 충족도가 높아 면접으로 확인할 만함 |
| 추가 확인 | fit_score 3. 적합 여부를 판단하려면 추가 정보가 필요함 |
| 보류 | fit_score 1~2. 현 시점에서 요건 충족이 낮음 |

# 지켜야 할 것

1. action은 **제안**이다. "합격시켜라", "탈락시켜라"가 아니다.
2. reasons는 이전 단계의 fit·concerns를 근거로 쓴다. 새로운 사실을 만들지 않는다.
3. check_points는 면접관이 실제로 물어볼 수 있는 구체적 질문이어야 한다.
4. 한국어 평서체로 쓴다.
