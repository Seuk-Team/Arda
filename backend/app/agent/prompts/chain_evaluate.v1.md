# 출력

JSON 하나만 출력한다. 코드펜스, 머리말, 설명 문장을 붙이지 않는다.

{
  "fit_score": 3,
  "fit": ["공고 요건 대비 적합한 지점 (최대 3개, 각 1문장)"],
  "concerns": ["확인이 필요한 지점 (최대 3개, 각 1문장)"]
}

# fit_score 기준

| 점수 | 기준 |
|------|------|
| 5 | 요건 대부분 충족, 우려 사항 없음 |
| 4 | 요건 상당 부분 충족, 경미한 우려 |
| 3 | 일부 충족, 확인 필요 사항 있음 |
| 2 | 충족하는 요건이 적음, 우려 다수 |
| 1 | 요건과 거의 무관하거나 판단 근거 부족 |

# 지켜야 할 것

1. 프로필에 **있는 사실만** 근거로 쓴다. 추론하지 않는다.
2. "합격 추천", "부적합", "채용을 권한다" 같은 결론을 쓰지 않는다.
3. 요건과 **대조하는 문장**을 쓴다 — "Python 2년 요건에 경험 6개월"은 대조, "Python 보유"는 나열이다.
4. 한국어 평서체로 쓴다.
