## 1. 미션

버튼으로 안 되는 작업을 에이전트로. **① 이력서 비정형→정형 추출 ② 도구 호출 에이전트 ③ RAG 질의응답(보조)** — 세 가지 전부에서 **최종 확정은 항상 사람**이다 (앰버 점선 = AI 제안 / 잎초록 실선 = 사람 확정, [05-design.md](../00_overview/05-design.md) §1).

## 2. 범위

**포함**

- **이력서 구조화 추출**: pdf·docx·hwp 텍스트 추출(텍스트 PDF만, 스캔본 제외·HWP 실패 시 수동 폴백) → 경력·기술·학력 구조화 필드 + **담당자용 요약문**(`applications.ai_summary`) 생성. 접수 시 1회 생성·저장, 재생성은 명시적 버튼으로만 ([01-erd.md](../00_overview/01-erd.md) applications 비고)
- **도구 호출 에이전트**: 자연어 한 문장 → 검색·조회(읽기) / 단계 변경·메일 초안(쓰기) 도구 순차 호출. **쓰기 도구는 반드시 확인 단계를 거친다** ("김도현을 불합격으로 옮길까요?"). 메일은 초안까지 — 발송은 사람이 확정
- 에이전트 API 라우터(`backend/app/api/agent.py`)와 그 UI 스펙 (UI 구현은 cloverky와 협업 — 프론트 파일 PR은 프론트 오너 승인)
- (여유) **STT 입력**: Whisper API → 엔티티 해석 레이어(이름 유사도 매칭·기술 용어 음차 정규화·한글 수사→숫자) → 기존 텍스트 에이전트. 응답은 텍스트 (ADR-0004)
- (여유) RAG 질의응답 — ①②의 보조

**제외**

- 최종 합불 자동 확정 — 영구 제외 (ADR-0003)
- speech-to-speech · TTS — ADR-0004 (TTS는 여유 시 한 줄)
- 표정분석·SNS 크롤링 — ADR-0002 등 기존 제외 유지

- 기본: `claude-opus-5` (입력 $5 / 출력 $25 per 1M tokens) — 도구 호출 정확도가 데모 품질을 좌우한다

- **비용 가드 (필수)**: ⑴ 더미 10만 건에 LLM 호출 금지 — J7 더미는 `ai_summary` NULL 또는 문장 은행으로 채운다 (10만 건 × $0.03 = $3,000 사고 방지) ⑵ 호출마다 토큰 사용량 로깅 ⑶ API 키는 `.env`, 코드·로그에 남기지 않는다

## 6. 품질 기준 (전 마일스톤 공통)

- **환각 가드**: 응답은 도구 결과만 인용. 존재하지 않는 지원자·수치를 만들면 실패로 취급하고 프롬프트를 수정한다
- **확정은 사람**: AI가 만든 모든 것은 앰버 점선 상태로 시작하고, 사람의 명시적 액션으로만 실선이 된다
- **재현성**: 프롬프트는 코드로 버전 관리 (`backend/app/agent/prompts/`), 모델명·토큰 사용량 로깅

## 7. 리스크

- **코어 API 지연 시 도구를 붙일 데가 없다** → M1을 API 무관 작업(추출 PoC·UI 시안·프롬프트 설계)으로 구성했고, 전환기에 본인이 E2(평가 API)를 직접 만들어 선행을 스스로 푼다.
- **HWP 추출 불안정** → 처음부터 "실패 시 수동 입력 폴백"을 설계에 포함 (05-design §0.5 확정 사항).
- **비용 폭주** → §3 비용 가드 3종.

## 8. 면접 스토리

- 도구 호출 에이전트 설계 — 한 문장이 검색→필터→상태변경→문서 생성으로 분해되는 과정, **왜 쓰기 도구에만 확인 단계를 강제했는가**
- (STT 시) **음성 인식 오류가 도구 호출로 전파되는 것을 어떻게 막았는가** — 엔티티 해석 레이어
- 왜 "버튼으로 되는 일"에 에이전트를 쓰지 않았는가 (ADR-0003의 원칙을 본인 언어로)
