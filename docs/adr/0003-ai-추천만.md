# ADR-0003. AI는 추천까지만, 확정은 사람

- 상태: 확정 (강사 피드백 검토 후)

## 맥락

AI가 이력서를 읽고 요건 매칭·점수화·랭킹까지 자동 판정하자는 제안이 있었다. 그러나:

- EU AI Act는 채용을 고위험으로 분류해 인적 감독을 요구
- 미국 EEOC도 자동 스크리닝이 장애인을 걸러내면 ADA 위반 소지가 있다고 경고
- 사람 검토 없는 자동 탈락은 심사에서 바로 지적당하는 지점

또한 원칙: **버튼으로 되는 일은 버튼으로 한다. 에이전트는 버튼으로 안 되는 작업에만 쓴다.**

## 결정

- AI는 점수화·랭킹·추천까지. **최종 합불 확정은 항상 사람이 누른다.**
- UI 규약: 앰버 점선 = AI 제안 / 청록 실선 = 사람 확정. AI 점수 박스에 "확정은 담당자가 합니다" 상시 표기.
- 적용 우선순위(여유 시): ① 이력서 비정형→정형 추출(검색·필터의 재료) ② 도구 호출 에이전트(검색+필터+상태변경+메일 초안, 발송은 사람 확정) ③ RAG 질의응답(①②의 보조)

## 결과

발표 효과는 동일(수십 명 몇 초 만에 점수순 정렬)하면서 "왜 사람 확정을 남겼나"라는 답할 거리가 생긴다.
