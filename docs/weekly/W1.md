## 5. 충돌 방지

**원칙: 한 사람 = 자기 파일. 두 사람이 같은 파일을 열지 않는다.**

| 팀원 | 이번 주에 만드는 파일 |
|---|---|
| 팀원1 | `mockup-login.html` · `mockup-apply.html` · `docs/email-templates.md` |
| 팀원2 | `mockup-applicants.html` · `mockup-mobile.html` |
| 팀원3 | `mockup-postings.html` · `mockup-dashboard.html` · `docs/presentation-outline.md` |
| 팀원4 | `mockup-evaluations.html` · `mockup-settings.html` · `docs/qa-scenarios.md` |

**같은 파일이 두 번 나오지 않는다 → 이번 주 머지 충돌은 구조적으로 0이다.**
파일이 겹치지 않으므로, 남는 의존은 "복사할 원본이 머지됐는가" 하나뿐이다.

```
mockup.html (이미 있음, 아무도 안 건드림)
├── A1 로그인 ──┬── A2 설정   (.tfield .tinput 복사)
│               └── C1 지원폼 (.tfield .tinput 복사)
├── B1 공고목록 ── 대시보드   (링크 대상)
├── E1 평가현황      (독립)
├── H1 통합검색      (독립)
└── 모바일 리스트    (독립)
```

- **공용 파일은 아무도 고치지 않는다.** 고쳐야 하면 팀 채널 → 팀장이 처리.
  - 공용: `frontend/mockups/mockup.html` · `docs/01-erd.md` · `docs/02-api.md` · `backend/app/models.py`
- 자기 지시서에 없는 파일이 `git status`에 뜨면 되돌리고 팀 채널에 알린다.
