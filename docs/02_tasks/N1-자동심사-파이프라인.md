## 배경

팀장이 정한 8단계 프로세스(2026-09-10): 접수 → 아르 서류 점수·합불 → 서류 합격자만 면접(인적성 발송) → 면접관 자동 배정 → 아르 면접 점수(답변 대조 + 진위) → 서류+면접 가중 합계 → 최종 합불만 사람. 지금 시스템은 이 중 "접수·요약·카드 옮기기·일정 제안·면접·인적성" 부품은 있으나 **점수화·자동 이동·자동 배정·합계**가 없다.

## 단계 매핑 (8단계 ↔ 시스템)

| 팀장 단계 | 시스템 | 상태 |
|---|---|---|
| 1 접수 | 공개 폼 · 담당자 등록 · (예정) 아르 파일 접수 | 있음 / 파일 접수는 N2 |
| 2 아르 서류 판정 | 요약 2단계 → `doc_score`(100) → 임계 비교 → `applied→screening→interview` 또는 `→rejected` | **이 지시서** |
| 3 서류 합격자만 면접·인적성 | 면접 단계 진입 시 인적성 세션+메일 자동 | **이 지시서** |
| 4 면접관 자동 배정(관리자만 수동) | `posting_interviewers` 풀 → 가용시간·배정 적은 순 → 일정 제안 자동 | **이 지시서** |
| 5 면접까지 요약 | `interview_findings`(기존) + `ai_score_detail` | **이 지시서** |
| 6 요건 맞을수록 높은 점수 · 면접 점수 | 서류: 요건·우대·인재상 가중 / 면접: 답변 대조 70 + 진위 30 | **이 지시서** |
| 7 합계 | `final_score` = 서류×w + 면접×w, 등급 S/A/B/C | **이 지시서** |
| 8 최종 합불 사람 | `accepted`·면접 뒤 `rejected` 는 사람만 | 그대로 |

## 점수 규칙 (원본)

```
서류 doc_score  = req×w_req + pref×w_pref + culture×w_culture     (w 합 = 100, 기본 50/20/30)
면접 ai_score   = answers×w_ans + truth×w_truth                     (기본 70/30, truth 표본 없으면 answers 100%)
최종 final      = doc×w_doc + interview×w_itv                        (기본 50/50, 면접 없으면 null)
등급            = S ≥85 · A ≥70 · B ≥55 · C
서류 자동 이동  = doc_score ≥ posting.pass_threshold(기본 60) → interview, 미만 → rejected
```

가중치는 `company_profile.scoring_weights` JSON 한 곳. 임계는 공고별.
