## 3. 관리자 채점 기준 설정 — 중단했다가 이어서 마무리

PR #365 세션이 머지 뒤 요청 없이 시작해 비용 문제로 멈췄던 작업(WIP `3fbc0e2`)을, 같은 날 사용자가 "점수 관련 항목을 관리자가 % 나 가중치로 직접 설정하게" 요청해 이어서 마무리했다. 계기는 AI 면접 점수의 진위 지표(목소리·얼굴, 정확도 약 76%)가 기본 면접 안 30%, 최종 약 15% 로 들어가 있어 발표 문구("표정은 참고만")와 어긋난다는 지적이다 — 관리자가 화면에서 0% 로 내릴 수 있게 됐다. 기본값(30)은 바꾸지 않았다.

## 아직 아무도 안 한 후보 (원래 제안 3번)

- 같은 입력이면 저장값 재사용: (서류 SHA-256 + 공고 요건 + 가중치 + 프롬프트 버전 + 모델) 해시를 키로 점수 저장, 같으면 다시 채점하지 않는다. 서류 지문은 `shared/anchoring.py` 가 이미 뜬다.
- 재생성 버튼이 점수를 덮어쓰지만 판정은 안 바꾼다 → 단계 이력의 판정 점수와 화면 점수가 어긋날 수 있다. 재생성 전 점수를 `doc_score_detail` 에 남기는 정도로 충분할 수 있다.
