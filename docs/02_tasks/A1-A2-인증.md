## 가장 중요한 규칙

- **`backend/app/models.py`를 수정하지 않는다.** `User` 모델은 이미 있다 (`id`·`email`·`password_hash`·`name`·`role`·`created_at`).
- **`docs/00_overview/01-erd.md`·`docs/00_overview/02-api.md`를 수정하지 않는다.** 공용 문서다.
- **`main.py`는 `include_router` 한 줄만** 건드린다.
- **최초 admin 계정은 이 API로 만들지 않는다.** `/auth/signup`은 인증되지 않은 호출자가 보낸 `role`을 무시하고 항상 `"recruiter"`로 고정한다. 이미 로그인한 `admin`이 `Authorization` 헤더를 들고 호출한 경우에만 `role`을 그대로 반영한다. 최초 admin은 별도 시드(직접 INSERT 또는 스크립트)로 넣는다 — 이 지시서 범위 밖.
- **JWT 시크릿은 하드코딩하지 않는다.** `db.py`의 `DATABASE_URL`과 같은 패턴으로 `os.getenv("JWT_SECRET", "dev-secret-change-me")` 형태 사용 — 개발용 기본값만 코드에 두고, 실제 값은 `.env`.
- **비밀번호는 평문으로 어디에도 남기지 않는다.** 저장은 `password_hash`(bcrypt)만.

```python
# backend/app/security.py (핵심만)
import os
from datetime import datetime, timedelta, timezone

import bcrypt
import jwt

JWT_SECRET = os.getenv("JWT_SECRET", "dev-secret-change-me")
JWT_ALGORITHM = "HS256"
JWT_EXPIRES_MINUTES = 60 * 12


def hash_password(raw: str) -> str:
    return bcrypt.hashpw(raw.encode(), bcrypt.gensalt()).decode()


def verify_password(raw: str, hashed: str) -> bool:
    return bcrypt.checkpw(raw.encode(), hashed.encode())


def create_access_token(user_id: int, role: str) -> str:
    payload = {
        "sub": str(user_id),
        "role": role,
        "exp": datetime.now(timezone.utc) + timedelta(minutes=JWT_EXPIRES_MINUTES),
    }
    return jwt.encode(payload, JWT_SECRET, algorithm=JWT_ALGORITHM)


def decode_access_token(token: str) -> dict:
    return jwt.decode(token, JWT_SECRET, algorithms=[JWT_ALGORITHM])
```

```python
# backend/app/deps.py
from fastapi import Depends, HTTPException, status as http
from fastapi.security import HTTPAuthorizationCredentials, HTTPBearer
from sqlalchemy.orm import Session

from app.db import get_db
from app.models import User
from app.security import decode_access_token

bearer_scheme = HTTPBearer(auto_error=False)


def get_current_user(
    creds: HTTPAuthorizationCredentials | None = Depends(bearer_scheme),
    db: Session = Depends(get_db),
) -> User:
    if creds is None:
        raise HTTPException(http.HTTP_401_UNAUTHORIZED, "인증이 필요합니다")
    try:
        payload = decode_access_token(creds.credentials)
    except Exception:
        raise HTTPException(http.HTTP_401_UNAUTHORIZED, "유효하지 않은 토큰입니다")
    user = db.get(User, int(payload["sub"]))
    if user is None:
        raise HTTPException(http.HTTP_401_UNAUTHORIZED, "유효하지 않은 토큰입니다")
    return user


def get_current_user_optional(
    creds: HTTPAuthorizationCredentials | None = Depends(bearer_scheme),
    db: Session = Depends(get_db),
) -> User | None:
    if creds is None:
        return None
    try:
        return get_current_user(creds, db)
    except HTTPException:
        return None
```

```python
# backend/app/api/auth.py (핵심만)
from fastapi import APIRouter, Depends, HTTPException, status as http
from sqlalchemy.exc import IntegrityError
from sqlalchemy.orm import Session

from app.db import get_db
from app.deps import get_current_user_optional
from app.models import User
from app.schemas.auth import LoginRequest, SignupRequest, TokenResponse, UserOut
from app.security import create_access_token, hash_password, verify_password

router = APIRouter(prefix="/api/v1/auth", tags=["auth"])


@router.post("/signup", response_model=UserOut, status_code=http.HTTP_201_CREATED)
def signup(
    body: SignupRequest,
    db: Session = Depends(get_db),
    caller: User | None = Depends(get_current_user_optional),
):
    role = body.role if (caller and caller.role == "admin") else "recruiter"
    row = User(email=body.email, name=body.name, role=role,
               password_hash=hash_password(body.password))
    db.add(row)
    try:
        db.flush()
    except IntegrityError:
        db.rollback()
        raise HTTPException(http.HTTP_409_CONFLICT, "이미 가입된 이메일입니다")
    db.commit()
    return UserOut.model_validate(row)


@router.post("/login", response_model=TokenResponse)
def login(body: LoginRequest, db: Session = Depends(get_db)):
    user = db.query(User).filter(User.email == body.email).first()
    if user is None or not verify_password(body.password, user.password_hash):
        raise HTTPException(http.HTTP_401_UNAUTHORIZED, "이메일 또는 비밀번호가 올바르지 않습니다")
    token = create_access_token(user.id, user.role)
    return TokenResponse(access_token=token, token_type="bearer")


@router.get("/me", response_model=UserOut)
def me(user: User = Depends(get_current_user)):
    return UserOut.model_validate(user)
```

## 검증 방법

```bash
cd backend && uv run uvicorn app.main:app --reload
# 다른 터미널에서
curl -s -X POST localhost:8000/api/v1/auth/signup -H 'content-type: application/json' \
  -d '{"email":"a@b.com","password":"pw12345","name":"홍길동","role":"admin"}'
curl -s -o /dev/null -w '중복 %{http_code}\n' -X POST localhost:8000/api/v1/auth/signup \
  -H 'content-type: application/json' -d '{"email":"a@b.com","password":"pw12345","name":"홍길동"}'
TOKEN=$(curl -s -X POST localhost:8000/api/v1/auth/login -H 'content-type: application/json' \
  -d '{"email":"a@b.com","password":"pw12345"}' | python3 -c 'import sys,json;print(json.load(sys.stdin)["access_token"])')
curl -s -o /dev/null -w '오답 %{http_code}\n' -X POST localhost:8000/api/v1/auth/login \
  -H 'content-type: application/json' -d '{"email":"a@b.com","password":"wrong"}'
curl -s localhost:8000/api/v1/auth/me -H "authorization: Bearer $TOKEN"
curl -s -o /dev/null -w '토큰 없음 %{http_code}\n' localhost:8000/api/v1/auth/me
```

기대 결과:

- 첫 가입 → **201**. 인증 없이 호출했으므로 `role` 은 `"admin"`을 보내도 응답은 `"recruiter"`로 고정
- 같은 이메일 재가입 → **409**
- 로그인 성공 → JWT 문자열
- 비밀번호 오답 → **401**
- `/me`에 유효한 토큰 → 가입한 사용자 정보, `password_hash` 없음
- `/me`에 토큰 없음 → **401**
- 서버 로그에 트레이스백이 없다
