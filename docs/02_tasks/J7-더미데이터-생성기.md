# [J7] 더미 데이터 — 재료 사전·문장 은행(지금 바로) + 생성 스크립트(스키마 확정 후)

> 담당: 파트 A는 누구나(배치 단위로 나눠서) · 파트 B는 B 역할 · 브랜치: `feat/j7-seed-<배치번호>` / `feat/j7-generator`

## 배경

검색·인덱스 튜닝(B 파트)은 10만 건이 있어야 의미가 있다. 그런데 **Claude가 행을 한 줄씩 뽑는 방식은 토큰 낭비**라, 구조를 둘로 나눈다.

- **파트 A — 재료 (Claude, 토큰 소량, 배치로 나눠서)**: 현실적인 이름·학교·기술 조합 패턴과, 자기소개서용 **문장 은행**(5카테고리 × 200문장 = 1,000문장)을 JSON 파일로 만든다. 한 번 만들면 끝.
- **파트 B — 조립 (스크립트, 0토큰)**: 재료를 조합해 지원서 10만 건을 DB에 넣는다. 문장 은행 조합 덕에 자소서가 전원 다르다.

파트 A는 코드·DB 없이 지금 바로 할 수 있고, 여러 사람이 배치를 나눠 맡는다.

## 파트 A — 재료 사전 · 문장 은행

### 파일 규격

```
backend/scripts/seed/
├─ materials/
│  ├─ names.json           # {"last":[...50+], "first":[...300+]}  성·이름 풀
│  ├─ schools.json         # [{"school":"OO대학교","majors":["컴퓨터공학과",...]}, ...] 30+
│  └─ skill-patterns.json  # [{"track":"backend","skills":["Python","FastAPI",...]}, ...] 직군별 기술 조합 10+
└─ sentences/
   ├─ motivation-01.json   # 지원동기   100문장
   ├─ motivation-02.json   # 지원동기   100문장
   ├─ growth-01.json … growth-02.json        # 성장과정
   ├─ strength-01.json … strength-02.json    # 강점
   ├─ experience-01.json … experience-02.json # 경험
   └─ goal-01.json … goal-02.json            # 포부
```

문장 파일 형식: `[{"text":"{{학교}}에서 {{전공}}을 공부하며 …", "vars":["학교","전공"]}, …]`
- 허용 변수: `{{학교}}` `{{전공}}` `{{기술}}` `{{경력}}` `{{직무}}` `{{회사명}}` — 이 외 변수 금지
- 한국어 자기소개서체(존댓말), 40~120자, 같은 파일 안 중복·유사문 금지, 카테고리 주제 이탈 금지

3. 아래 프롬프트에서 배치 번호·파일명만 바꿔 Claude Code에 붙여넣는다.
4. `python backend/scripts/seed/check_batch.py <파일>` 실행 → 통과해야 한다.
