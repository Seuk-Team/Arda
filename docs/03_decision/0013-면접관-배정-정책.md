# ADR-0013. 면접관 배정 정책

- 상태: **v1 확정** — 추후 변동 가능
- 작성: suvisdev (에이전트)
- 선행: [ADR-0003](0003-ai-추천만.md) · [ADR-0012](0012-서류심사-AI-분류기준.md)
- 로드맵: [role/agent.md](../01_role/agent.md) §5 W2~W3

## 맥락

서류심사(ADR-0012)를 통과한 지원자에게 면접관을 배정해야 한다.
회사 규모에 따라 면접관이 2~3명인 곳도, 수십 명인 곳도 있으므로 수동·자동 두 방식을 모두 지원한다.
모든 배정 권한은 어드민 계정에 있다.

## 배정 방식

### 1. 수동 배정

- 어드민이 면접관 목록에서 직접 선택하여 배정
- 건수도 직접 조정 가능
- 소규모 회사에서 유용

### 2. 자동 배정

- 회사가 설정한 기준에 따라 AI가 면접관 추천
- **가중 라운드로빈**으로 건수 자동 분배
- 최종 배정은 어드민이 확인 버튼을 눌러야 완료 (AI 추천 → 어드민 확인)

## 자동 배정 기준 (회사별 설정)

| 항목 | 설명 |
|---|---|
| **전문 분야 매칭** | 지원자 기술/직무 ↔ 면접관 전문 분야 비교 |
| **면접관 수** | 지원자당 1~5명, 회사별·면접 차수별 설정 가능 |
| **기타 조건** | 부서, 직급, 면접 교육 이수 등 자유 추가 |

## 가중 라운드로빈

면접관마다 가중치(정수)를 부여한다. 가중치가 높으면 더 많은 면접을 맡는다.

- 예: A(3), B(2), C(1) → A:B:C = 50%:33%:17%
- 지원자가 1명만 들어와도 즉시 배정 가능 (전체 인원 불필요)
- 면접관 추가/제거 시 가중치만 변경하면 됨

퍼센티지 대신 가중치를 쓰는 이유: 실시간으로 지원자가 유입되므로 전체 수를 미리 알 수 없다.

## 편향 방지 — 경고 (차단 아님)

동일 면접관이 연속 N건 이상 배정되면 경고를 띄운다.

- 기본값: 연속 3건 (회사별 조정 가능)
- **차단이 아니라 경고**: 소규모 회사는 면접관이 부족할 수 있으므로, 어드민이 판단하여 진행 가능

## 이의신청

면접관이 배정을 거절해야 할 때 사유와 함께 이의신청할 수 있다.

- 사유 예시: 지원자와 개인적 면식, 일정 변경, 해당 분야 전문성 부족
- 어드민이 확인 후 교체 여부 결정
- 이의신청 없이도 어드민이 직접 교체 가능

## 권한 정리

| 행위 | 권한 |
|---|---|
| 면접관 배정 | 어드민만 |
| 면접관 교체 | 어드민만 |
| 면접관 등록 | 어드민만 |
| 이의신청 | 면접관 (어드민 승인 필요) |

## v1 범위

- 수동 배정 (어드민 직접)
- 자동 배정 (가중 라운드로빈)
- 면접관 수 설정 (회사별)
- 가중치 설정 (면접관별)
- 동일 면접관 반복 경고
- 어드민 교체 기능
- 면접관 등록 (어드민만)
- 면접관 이의신청 (사유 + 어드민 승인)

## v2 이후 검토

- 면접관 일정 관리 (가용 날짜 설정)
- 면접 일시 자동 잡기 (캘린더 연동)
- 면접관 배정 패턴 분석 (자동 배치 시 참고용, 확정 아님)

## 감수하는 것

- 가중 라운드로빈이 모든 상황에 최적은 아니다 — 수동 조정으로 보완
- 경고 기본값(3건)이 모든 회사에 맞지 않을 수 있다 — 설정으로 조정
- 이의신청 남용 가능성 — 어드민 승인 필수로 방지
