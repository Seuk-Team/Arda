# ADR-0029. 표정·음성으로 진위를 판별한다 — ADR-0002·0026 결정 2 를 뒤집는다

> **상태: 확정 · 2026-09-07** (개정 협업 규칙에 따라 직접 반영, 사후 공지)
> **대체**: [ADR-0002 표정분석 제외](0002-표정분석-제외.md) · [ADR-0026 결정 2](0026-AI-면접-음성분석-제외.md)
> **유지**: [ADR-0003 AI는 추천까지만](0003-ai-추천만.md) · [ADR-0026 결정 3·4](0026-AI-면접-음성분석-제외.md)
> 관련: `ai/lie-detection` · PR #42(배포) · [presentation-outline §4](../presentation-outline.md)

## 문제

면접 영상에서 표정·음성 특징을 뽑아 진실/거짓을 분류하는 서비스(`ai/lie-detection`)가 **이미 만들어져 main 에 있다.** 강사 피드백에서도 이 방향이 나왔고, 운영에 배포하는 PR(#42)이 올라와 있다.

그런데 우리는 같은 기능을 **두 번 자른 적이 있다.**

- [ADR-0002](0002-표정분석-제외.md) — 실시간 표정분석 제외 (확정)
- [ADR-0026](0026-AI-면접-음성분석-제외.md) 결정 2 — 음성 기반 감정·기만 추론 제외 (확정)

**문서와 코드가 갈린 채로 발표에 갈 수는 없다.** 둘 중 하나를 고쳐야 하고, 팀은 코드를 살리는 쪽을 골랐다.

## 결정

**1. 표정·음성 기반 진위 판별을 정식 기능으로 도입한다.** `ai/lie-detection` 을 별도 서비스로 운영하고, 면접 결과 화면에서 담당자가 볼 수 있게 한다.

**2. 판정 결과를 평가 점수에 자동으로 반영하지 않는다.** [ADR-0003](0003-ai-추천만.md)("AI는 추천까지만, 확정은 사람")은 **그대로 유지한다.** 담당자 화면에 표시하고, 합불은 사람이 정한다.

**3. 판정과 함께 그 한계를 같은 화면에 적는다.** 숫자만 띄우지 않는다 — 아래 §"우리가 받아들이는 것" 의 정확도와 데이터 출처를 화면에서 읽을 수 있어야 한다.

**4. 지원자에게 고지하고 동의를 받는다.** 현재 면접 동의는 `녹음·전사·보관` 세 가지뿐이다. **표정·음성으로 진위를 추론한다는 것은 여기 없다.** 동의 문구를 고치기 전에는 운영에 켜지 않는다.

**5. 진행 보조(`app/interview_pacing.py`)는 이 결정과 분리한다.** 그쪽은 계속 **점수 없음·저장 없음·심리 추론 없음**으로 둔다 ([ADR-0026 결정 4](0026-AI-면접-음성분석-제외.md) 유지). 판정은 별도 서비스가 하고, 진행 보조는 면접을 매끄럽게 하는 것이 전부다. **둘을 섞으면 "점수에 안 들어간다"는 약속이 어디까지 유효한지 아무도 모르게 된다.**

## 우리가 받아들이는 것 — 앞 ADR 의 이유는 사라지지 않는다

결정을 뒤집는다고 그때의 근거가 틀린 것이 되지는 않는다. **리스크로 남고, 우리가 그걸 안고 간다.** 발표에서 물으면 답할 수 있어야 하므로 여기 적는다.

### 정확도 — 4번에 1번은 틀린다

| | |
|---|---|
| 모델 | MLP (5-fold 교차검증 채택) |
| **정확도** | **76.0%** |
| 학습 데이터 | **Michigan Real-Life Trial** — 실제 법정 증언 영상 |
| 표본 수 | **거짓 61 · 진실 60 = 121개** |

**두 가지를 정직하게 말해야 한다.**

1. **76% 는 4번 중 1번 틀린다는 뜻이다.** 지원자 20명이면 5명 가까이가 잘못 분류된다.
2. **학습 데이터가 우리 상황이 아니다.** 영어권 법정 증언이고, 우리는 한국어 화상 면접이다. **121개 표본에서 나온 76% 가 우리 지원자에게 재현된다는 근거가 없다.** 우리 데이터로 재 본 적이 없다.

→ **발표에서 "76% 정확도"를 그냥 말하면 안 된다.** "법정 증언 데이터 121건에서 76%였고, 우리 면접 데이터로는 아직 재지 않았다"까지가 우리가 아는 전부다.

### 지원자가 반박할 수 없다

[ADR-0026](0026-AI-면접-음성분석-제외.md) 결정 3 의 대조 방식은 **양쪽 원문을 인용**하므로 지원자가 "그렇게 말한 적 없다"고 다툴 수 있다. **표정·음성 판정은 그게 안 된다.** "눈 깜빡임 0.8회/초"에 지원자가 할 말이 없다.

그래서 결정 2(점수에 자동 반영 안 함)와 결정 3(한계를 같이 표시)이 붙어 있는 것이다. 이 둘이 빠지면 **반박할 수 없는 근거로 사람을 떨어뜨리는 시스템**이 된다.

### 우리가 스스로 세운 기준을 넘는다

ADR-0026 은 이렇게 적어 뒀다.

> **그 숫자를 보고 면접관이 무엇을 해야 하는지 우리가 답할 수 있는가. 답할 수 없으면 만들지 않는다.**

이 결정은 그 기준을 **통과해서가 아니라 기준을 바꿔서** 내려졌다. 지금 답은 "판정을 참고하되 사람이 정한다"이고, 그게 충분한지는 운영해 봐야 안다.

## 화면에서 지킬 것

- **`observations` 는 판정 근거가 아니다.** 서비스 README 에 적힌 대로 "평균에서 벗어났다"는 표시일 뿐이다. `flag: high` 를 빨강으로 칠해 거짓의 증거처럼 보이게 하지 않는다
- **`lie_pct` 를 단독으로 크게 띄우지 않는다.** 정확도와 데이터 출처를 같은 화면에서 읽을 수 있어야 한다
- **"거짓말"이라는 단어를 판정 결과 라벨로 쓰지 않는다.** 우리가 가진 것은 분류기의 출력이지 사실이 아니다

## 발표에서 말할 것

바뀐 프레이밍이다. 기존 "우리는 목소리로 사람을 판단하지 않는다" 는 **더 이상 쓸 수 없다.**

> **"표정·음성으로 진위를 추론하는 모델을 붙였다. 정확도는 법정 증언 데이터 121건에서 76%이고, 우리 면접 데이터로는 아직 재지 않았다. 그래서 점수에 자동으로 넣지 않고 면접관이 참고하는 자리에만 둔다."**

숫자를 크게 말하고 한계를 작게 말하면 그 자리에서 무너진다. **한계를 우리가 먼저 말한다.**

## 열려 있는 것

| | 누가 | 언제까지 |
|---|---|---|
| 지원자 동의 문구 개정 (결정 4) | 프론트 + 법률 확인 | **운영에 켜기 전** |
| 우리 면접 데이터로 정확도 재측정 | 미정 | 표본이 쌓인 뒤 |
| 판정 결과를 어느 화면 어디에 둘지 | 프론트 | 배포 후 |
| `ai/lie-detection` 서버 자원 (영상 1건 574MiB) | 인프라 | PR #42 와 같이 |

## 이 문서를 남기는 이유

**우리가 무엇을 포기했는지 나중에 알 수 있게 하기 위해서다.** ADR-0002·0026 은 "왜 안 하는가"를 남겼고, 이 문서는 "그걸 알면서도 왜 하는가"를 남긴다.

되돌리게 되면 이 문서의 §"우리가 받아들이는 것" 부터 읽으면 된다. 거기 적힌 것 중 하나가 실제로 터진 것일 가능성이 높다.
