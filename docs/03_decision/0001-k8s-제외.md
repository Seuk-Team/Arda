# ADR-0001. Kubernetes 제외

- 상태: 확정 (기획 단계)

## 맥락

인프라 스택으로 K8s 도입이 검토됐다. 그러나 한 달 안에 K8s를 "굴렸다"고 말하려면 배포 전략(rolling/blue-green), 오토스케일링, 헬스체크 튜닝 중 최소 하나는 실제로 다뤄야 한다. 서비스 기능까지 만들면서는 매니페스트 작성하고 파드 뜨는 수준이 한계이고, 그 수준은 면접에서 파고들면 방어가 안 된다.

## 결정

K8s를 빼고 **Docker + AWS + GitHub Actions CI/CD**까지를 목표로 한다.

## 결과

- 신입 기준 충분한 셀링 포인트를 4주 안에 실제로 완성 가능
- 면접 답변: "못 만들어서가 아니라, 한 달 규모에서 설명 가능한 깊이까지 못 가기 때문에 뺐다"
