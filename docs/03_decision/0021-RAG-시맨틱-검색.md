# ADR-0021. RAG 파이프라인 — 임베딩 기반 시맨틱 검색

> **상태: 확정 · 2026-08-31** · W3 착수 예정
> 관련: [ADR-0012 서류심사 AI 분류기준](0012-서류심사-AI-분류기준.md) · [ADR-0011 에이전트 모델 비용](0011-에이전트-모델-비용.md)

## 문제

현재 지원자 검색은 `ILIKE`로 이름·이메일만 매칭한다. "Python 경험 3년 이상인 사람" 같은 의미 기반 검색이 불가능하다. 자기소개서(`self_intro`)와 스킬(`skills`) 데이터가 DB에 있지만 활용되지 않고 있다.

## 결정

pre-trained 한국어 임베딩 모델 + pgvector로 시맨틱 검색을 추가한다.

### 아키텍처

```
리크루터 질문 → 에이전트(Claude) → search_applications 도구
                                      ├─ 기존: ILIKE (이름·이메일)
                                      └─ 추가: 벡터 유사도 검색 (self_intro + skills)
```

### 구성 요소

| 요소 | 선택 | 근거 |
|------|------|------|
| 임베딩 모델 | `jhgan/ko-sroberta-multitask` | 한국어 sentence-transformers, pre-trained, 768차원 |
| 벡터 저장소 | pgvector (PostgreSQL extension) | 기존 PostgreSQL에 extension 추가만으로 사용, 별도 인프라 불필요 |
| 인덱스 | HNSW | 10만 건 규모에서 IVFFlat보다 recall 높음 |
| 청킹 | self_intro 전체 + skills 배열 join | self_intro가 수백~수천 자 수준이라 청킹 불필요, 단일 벡터 |

### 데이터 흐름

1. **지원서 제출 시**: `self_intro` + `skills` 텍스트를 임베딩 → `application_embeddings` 테이블에 저장
2. **검색 시**: 질의 텍스트를 임베딩 → pgvector `<=>` (코사인 거리) 연산으로 상위 N건 반환
3. **결과 병합**: ILIKE 결과와 벡터 결과를 합쳐서 중복 제거 후 반환

### 변경 대상

| 파일 | 변경 내용 |
|------|-----------|
| `backend/app/models.py` | `ApplicationEmbedding` 테이블 추가 (application_id FK, embedding Vector(768)) |
| `backend/app/agent/tools/read.py` | `search_applications`에 벡터 검색 분기 추가 |
| `backend/app/agent/embedder.py` | 신규 — 임베딩 생성·캐싱 모듈 |
| `backend/requirements.txt` | `sentence-transformers`, `pgvector` 추가 |
| `alembic/` 또는 DDL | pgvector extension + HNSW 인덱스 |

### 비용 가드 (ADR-0011 준수)

- 임베딩 모델은 로컬 실행 (API 호출 비용 없음)
- 더미 10만 건 시드 시 임베딩 일괄 생성은 별도 스크립트 — 서버 기동 시 자동 실행하지 않음
- 임베딩은 지원서 제출 시 1회만 생성, 이후 캐싱

## 범위에서 뺀 것

- 이력서 파일(PDF/DOCX) 본문 임베딩 — S3 연동 완료 후 별도 판단
- 임베딩 모델 fine-tuning — 실 사용 데이터 축적 후 검토
- 채용공고 임베딩 (공고 ↔ 지원자 자동 매칭) — ADR-0012 유사 능력 판별과 병합 시 검토

## 리스크

- 로컬 GPU 없는 환경에서 sentence-transformers CPU 추론 속도 — 768차원 단일 벡터라 수십 ms 수준, 허용 범위
- pgvector extension이 AWS RDS에서 지원됨 — 배포 환경 호환 확인 완료
- 더미 데이터 10만 건 일괄 임베딩 시 CPU 기준 약 30~60분 소요 — 시드 스크립트에 배치 처리 + 진행률 표시
