# 00. 프로젝트 개요

## 무엇을 만드는가

채용 지원자 관리 시스템(ATS). 채용담당자가 공고를 올리고, 지원자가 외부 링크로 지원서·이력서를 제출하면, 담당자·면접관이 칸반 보드에서 단계별로 심사·평가하고, 단계 변경 시 지원자에게 메일이 자동 발송된다.

- 1순위 목적: **이력서 대표 프로젝트** — 각자 면접에서 설명할 거리 확보
- 규모: 5인 · 5주 — **초기 버전 09/04(금) · 1차 완성 09/30(수)** (W1 08/24 시작, W5 09/25 종료 + 09/28~30 통합 버퍼)

## 스택

| 영역 | 선택 |
|---|---|
| 백엔드 | Python · FastAPI · PostgreSQL |
| 프론트엔드 | React · Vite · TypeScript |
| 에이전트 | Claude API (Python SDK) · Whisper API(STT, 여유) — 모델·비용은 [role/agent.md](../01_role/agent.md) §3에서 확정 |
| 앱 | **Flutter · Dart** — 확정 ([ADR-0010](../03_decision/0010-앱-flutter-확정.md) · [role/app.md](../01_role/app.md) §2) |
| 인프라 | Docker · AWS (EC2 · S3 · SES · SQS) · GitHub Actions |
| 배포 | 백엔드 AWS · 프론트 Vercel · 앱 **Android APK**(데모 — Android 전용) |
| 제외 | Kubernetes ([ADR-0001](../03_decision/0001-k8s-제외.md)) |

## 범위

**포함 (필수 27기능 — 전체 목록은 [planning/00_summary_ko.md](../04_planning/00_summary_ko.md) 6장)**

- 채용 공고 등록·관리 (B)
- 지원서 제출 + 이력서 S3 업로드 (C·F)
- 칸반 보드: 지원 접수 → 서류 검토 → 면접 → 최종 합격 / 불합격 (D)
- 단계 이력 기록 · 평가 코멘트 (D·E)
- 지원자 검색·필터 — 더미 10만 건 기준 튜닝 (H)
- 단계 변경 시 메일 발송 — SQS 비동기 + 재시도 (G)
- JWT 인증 · 역할 3종(관리자/채용담당자/면접관) (A)
- Docker · AWS 배포 · Swagger (J)

**제외 — 한 달에 불가**

- 실시간 동시 편집 / 외부 채용사이트 연동 / 통계 대시보드(여유 시 착수)
- 표정분석 ([ADR-0002](../03_decision/0002-표정분석-제외.md)) · SNS 크롤링 · 실시간 화상면접

**정식 트랙 2종 ([ADR-0008](../03_decision/0008-에이전트-앱-정식-트랙-승격.md)으로 "여유 시"에서 승격)**

- **에이전트**: 이력서 구조화 추출 · 도구 호출 에이전트 · RAG(보조). 최종 합불 확정은 항상 사람([ADR-0003](../03_decision/0003-ai-추천만.md)) — [role/agent.md](../01_role/agent.md)
- **앱**: 담당자·면접관용 모바일 앱 (조회·단계 변경·평가). 같은 API의 두 번째 클라이언트 — [role/app.md](../01_role/app.md)

두 트랙 모두 코어(필수 기능)가 우선한다. 코어 데모는 두 트랙 없이도 완결된다.

## 진행 순서 (주차별 — 도메인 기준, 상세·완료 기준은 각 로드맵의 주간 계획)

게이트 2개: **초기 버전 09/04(금)** → **1차 완성 09/30(수)**. 팀장 머지·검수는 매주 금요일 최소 1회(필요시 2~3회) — [04-team.md](04-team.md) 운영 리듬.

**초기 버전(09/04)의 정의** — 외부에 보여줄 수 있는 최소 동작 버전:

- 프론트: 전 화면이 목데이터로 동작하고 **Vercel URL로 접근 가능**
- 백엔드: 코어 API(인증 A1~A3 · 공고 B2 · 지원서 C2 · 지원자 D1·D4 · 평가 E2 · 검색 H2)가 **배포 URL의 Swagger에서 동작**
- **수직 슬라이스 1개**: 공개 지원 폼 제출 → DB 저장 → 담당자 쪽에서 확인까지 실데이터로 관통
- 에이전트·앱: 미포함 (산출은 UI 시안 ADR-0009 · 앱 스택 ADR-0010까지)
