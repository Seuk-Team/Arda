# 00. 프로젝트 개요

## 무엇을 만드는가

채용 지원자 관리 시스템(ATS). 채용담당자가 공고를 올리고, 지원자가 외부 링크로 지원서·이력서를 제출하면, 담당자·면접관이 칸반 보드에서 단계별로 심사·평가하고, 단계 변경 시 지원자에게 메일이 자동 발송된다.

- 1순위 목적: **이력서 대표 프로젝트** — 각자 면접에서 설명할 거리 확보
- 규모: 5인 · 4주 (실작업일 약 20일)

## 스택

| 영역 | 선택 |
|---|---|
| 백엔드 | Python · FastAPI · PostgreSQL |
| 프론트엔드 | React · Vite · TypeScript |
| 인프라 | Docker · AWS (EC2 · S3 · SES · SQS) · GitHub Actions |
| 배포 | 백엔드 AWS · 프론트 Vercel |
| 제외 | Kubernetes ([ADR-0001](adr/0001-k8s-제외.md)) |

## 범위

**포함 (필수 23기능 — 전체 목록은 [planning/00_summary_ko.md](planning/00_summary_ko.md) 6장)**

- 채용 공고 등록·관리 (B)
- 지원서 제출 + 이력서 S3 업로드 (C·F)
- 칸반 보드: 지원 접수 → 서류 검토 → 면접 → 최종 합격 / 불합격 (D)
- 단계 이력 기록 · 평가 코멘트 (D·E)
- 지원자 검색·필터 — 더미 10만 건 기준 튜닝 (H)
- 단계 변경 시 메일 발송 — SQS 비동기 + 재시도 (G)
- JWT 인증 · 역할 3종(관리자/채용담당자/면접관) (A)
- Docker · AWS 배포 · Swagger (J)

**제외 — 한 달에 불가**

- 실시간 동시 편집 / 외부 채용사이트 연동 / 통계 대시보드(여유 시 착수)
- 표정분석 ([ADR-0002](adr/0002-표정분석-제외.md)) · SNS 크롤링 · 실시간 화상면접

**AI (여유 시, [ADR-0003](adr/0003-ai-추천만.md))**: 이력서 구조화 추출, 도구 호출 에이전트. 최종 합불 확정은 항상 사람.

## 진행 순서 (주차별)

| | 1주차 | 2주차 | 3주차 | 4주차 |
|---|---|---|---|---|
| 프론트 | **정적 화면 (목데이터) — 최우선** | 정적 화면 완성 · **스키마 확정** | API 연동 | 칸반 완성 |
| 백엔드 | 스키마 초안 | CRUD · 전환 로직 | 검색·인덱스 | 통합·버그 |
| 인프라 | AWS 기본 배포 | 인증 | 메일 큐 | CI/CD |

진행 원칙: **UI(정적 화면)가 스펙이다.** 화면을 먼저 완성하고, 화면에 실제로 쓰인 데이터 기준으로 [01-erd.md](01-erd.md) 초안을 검증·확정한다. 확정 이후 스키마 변경은 전원 합의로만.
