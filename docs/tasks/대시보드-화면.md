# [대시보드] 화면 (정적 목업)

> 담당: (이름) · 브랜치: `feat/dashboard-mockup`
> **PR 단위**: 이 지시서 전체 = PR 1개
> **기능 번호 미지정** — 팀장이 붙인 뒤 발행한다

## 배경

로그인 후 첫 화면. 숫자 몇 개와 공고 카드로 "지금 뭘 해야 하는지"만 보여주고, 클릭하면 해당 화면으로 보낸다. **통계 차트는 범위 밖**([05-design](../05-design.md) §0.5). API 연결은 하지 않고 정적 HTML 목업 1장만 만든다.

## 시작 전에 읽는다

- [ ] [docs/05-design.md](../05-design.md) **전체를 한 번 읽는다**
- [ ] [CLAUDE.md](../../CLAUDE.md)의 "범위" 항목 — 자기 담당 파일 밖을 고치지 않는다
- [ ] [frontend/mockups/mockup.html](../../frontend/mockups/mockup.html)을 브라우저로 열어 **눈으로 본다**

## 선행 조건 — 없으면 중단

- [ ] `main`에 `mockup.html`이 있고 브라우저에서 열린다
- [ ] **복사 원본으로 지정된 파일의 PR이 머지돼 있다** — 이 화면의 복사 원본은 `mockup.html` 하나뿐이라 **바로 시작한다**. 카드 링크 대상인 `mockup-postings.html`(B1)은 없어도 `href`만 걸어두면 되고, 클릭 확인은 B1 머지 후에 한다

## 가장 중요한 규칙 — 새로 만들지 않는다

- 값은 전부 `mockup.html`의 `:root` 토큰으로. 직접 쓴 색·간격·폰트 크기 금지.
- 복사해 쓸 것: `.sidebar` `.nav` `.me` / `.head` `.head-top` `.title` / `.funnel` `.seg` `.flabels`(미니 퍼널 레일) / `.btn` `.btn-primary`
- 새로 만드는 것은 **숫자 카드(`.statcard`) 하나뿐**이다. 아래 완성 예시를 그대로 쓴다.
- 그 외에 목업에 없는 요소가 필요해지면 **멈추고 팀장에게 묻는다.**

## 완료 조건

- [ ] `frontend/mockups/mockup-dashboard.html` 1개 파일. `mockup.html`의 `:root` 토큰 블록과 필요한 클래스를 복사해 넣는다
- [ ] 사이드바는 `mockup.html`과 동일. `.active`만 "대시보드"로 옮긴다
- [ ] 헤더: 뒤로 가기 버튼 없음. 제목 "대시보드". 우측 버튼 없음
- [ ] 숫자 카드 3장을 가로로: **내 리뷰 대기 / 오늘 면접 / 진행중 공고**. 각 카드는 라벨(14px, `--text-sub`) + 숫자(26px `--font-display`, tabular-nums) + 단위
- [ ] 카드 클릭 시 이동: 리뷰 대기 → `mockup.html`, 오늘 면접 → `mockup.html`, 진행중 공고 → `mockup-postings.html`
- [ ] 그 아래 **공고별 카드 3장**. 각 카드에 공고명 + 마감(`D-12`) + `mockup.html`의 퍼널 레일(`.funnel` + `.seg` 5개)을 **작게** 복사해 넣는다. 클릭하면 `mockup.html`로 이동
- [ ] 퍼널 레일 색은 `mockup.html`에 있는 값 그대로 쓴다(무채 램프 3단 + 연두 + 적갈). **색을 바꾸지 않는다**
- [ ] 카드 hover / focus-visible 상태 정의 (05-design §6)
- [ ] 창 폭을 줄이면 카드가 세로로 쌓인다. 가로 스크롤 없음, 겹침 없음

## 완성 예시

숫자 카드는 목업에 없다. **아래를 그대로 복사해 쓴다. 값을 바꾸지 않는다.**

```html
<style>
.stats{ display:grid; grid-template-columns:repeat(auto-fit,minmax(220px,1fr)); gap:var(--sp-4); }
.statcard{ display:block; text-align:left; padding:var(--sp-5); cursor:pointer;
           background:var(--bg-elev); border:var(--border-w) solid var(--border);
           border-radius:var(--r-card); font-family:var(--sans);
           transition:background var(--dur-fast) var(--ease); }
.statcard:hover{ background:#F6F9F2; }
.statcard:focus-visible{ outline:2px solid var(--leaf); outline-offset:2px; }
.statcard .slabel{ display:block; font-size:var(--font-sm); color:var(--text-sub); white-space:nowrap; }
.statcard .snum{ display:block; margin-top:var(--sp-2); font-size:var(--font-display); font-weight:700;
                 color:var(--text); text-shadow:var(--ts-heading);
                 font-variant-numeric:tabular-nums; white-space:nowrap; }
.statcard .sunit{ font-size:var(--font-body); font-weight:600; color:var(--text-sub); margin-left:4px; }
</style>

<div class="stats">
  <a class="statcard" href="mockup.html">
    <span class="slabel">내 리뷰 대기</span>
    <span class="snum">12<span class="sunit">명</span></span>
  </a>
</div>
```

## Claude에게 시키기

**0 → 1 → 2 → 3 순서로 하나씩** 시킨다. 각 단계 후 브라우저로 확인하고 넘어간다.

```
0단계.
docs/05-design.md 전체와 frontend/mockups/mockup.html 을 읽어라.
이 화면에 적용되는 규칙을 5줄로 요약해서 보여줘라. 아직 파일을 만들지 마라.

1단계.
frontend/mockups/mockup-dashboard.html 을 만들어라.
mockup.html에서 :root 토큰 블록과 사이드바 전체를 복사하고, .active를 "대시보드"로 옮겨라.
헤더는 제목 "대시보드"만. 본문은 비워둔다. 새 색·새 간격 값을 만들지 마라.

2단계.
본문 위쪽에 숫자 카드 3장을 넣어라 — 내 리뷰 대기 12명 / 오늘 면접 3건 / 진행중 공고 4개.
지시서의 .stats/.statcard CSS를 그대로 복사해 쓴다. 값을 바꾸지 마라.
링크는 각각 mockup.html, mockup.html, mockup-postings.html.

3단계.
그 아래 공고별 카드 3장을 넣어라. 카드마다 공고명 + D-day + 퍼널 레일.
퍼널 레일은 mockup.html의 .funnel과 .seg를 복사해서 쓰고 색을 바꾸지 마라.
레일 아래 라벨은 넣지 말고 레일만. 카드 클릭 시 mockup.html로 이동.
```

**주의**: Claude가 스키마 변경, `mockup.html` 수정, 새 색·새 간격 값 추가, 차트 라이브러리 설치를 제안하면 **수락하지 말고** 팀 채널에 물어본다. **통계 차트는 범위 밖이다.**

## 검증 방법

```bash
python -m http.server 5500 --directory frontend/mockups
```

`http://localhost:5500/mockup-dashboard.html`

기대 결과:

- **`mockup.html`을 옆 탭에 함께 띄우고 나란히 비교한다.** 색·간격·글자 크기·모서리 반경·그림자가 눈으로 구분되지 않는다. 목업에 없는 요소를 새로 만들지 않았다
- 사이드바가 `mockup.html`과 눈으로 구분되지 않는다
- 숫자 카드에 마우스를 올리면 배경이 바뀌고, Tab으로 초록 포커스 링이 보인다
- 카드를 클릭하면 해당 화면으로 이동한다
- 창 폭을 줄이면 카드가 세로로 쌓이고 가로 스크롤이 없다
- 콘솔에 에러가 없다

## 막히면 · 되돌리기

- **30분 넘게 막히면 혼자 붙들지 말고 팀 채널에 묻는다.** 혼자 Claude와 씨름한 2시간이, 팀장이 5분에 답할 것을 이상한 결과물로 바꿔놓는다.
- **결과가 이상해지면 고치려 들지 말고 버린다.** 코드를 읽어 고치는 것보다 되돌리는 편이 빠르고 안전하다.

```bash
git checkout -- .
```

그래도 이상하면 브랜치째 버리고 처음부터 다시 시작한다.

```bash
git checkout main && git branch -D <브랜치명>
```

- **`git status`에 지시서에 없는 파일이 떠 있으면 Claude가 범위를 벗어난 것이다.** 그 변경은 되돌리고 팀 채널에 알린다.
