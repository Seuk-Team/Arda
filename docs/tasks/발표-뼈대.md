## 배경

최종 발표는 전원이 한 파트씩 말한다. 목차와 시연 순서를 미리 잡아두면 마지막 주에 자료 만들 때 헤매지 않고, 각자 "면접에서 말할 것"이 발표 파트와 일치하게 된다.

## 완료 조건

- [ ] `docs/presentation-outline.md`에:
  - 발표 목차(10~15분 기준, 섹션별 예상 시간)
  - 파트 배분표(역할 A~E ↔ 발표 섹션 매핑, 이름은 빈칸)
  - 시연 시나리오: 어떤 순서로 무엇을 보여줄지 (외부 지원 → 칸반/목록 → 단계 이동 → 메일 수신 → 검색 성능)
  - 시연 사고 대비: 데모 실패 시 대체(스크린샷/영상) 계획 한 줄
- [ ] 기술 어필 포인트가 각 역할의 "면접에서 말할 것"([docs/04-team.md](../04-team.md))과 1:1로 연결
