# [A1] 로그인 화면 (정적 목업)

> 담당: (이름) · 브랜치: `feat/a1-login-mockup`
> **PR 단위**: 이 지시서 전체 = PR 1개

## 배경

내부 사용자(관리자·채용담당자·면접관)가 들어오는 첫 화면. API 연결은 이 작업 범위가 아니고, **정적 HTML 목업 1장**만 만든다. 이후 React 이식은 팀장이 한다.

이 작업의 진짜 목적은 화면 1장이 아니라 **기존 시안을 베껴서 조립하는 방식에 적응하는 것**이다. 새로 디자인하는 부분은 없다.

## 선행 조건 — 없으면 중단

아래가 하나라도 아니면 **시작하지 말고 팀 채널에 알린다.**

- [ ] `main`에 [frontend/mockups/mockup.html](../../frontend/mockups/mockup.html)이 있고, 브라우저에서 열린다
- [ ] 직전 UI 작업 PR이 머지돼 있다 (날짜가 아니라 **머지**가 기준. 안 머지됐으면 기다린다)

## 가장 중요한 규칙 — 새로 만들지 않는다

- **색·간격·폰트 크기·radius·그림자·모션 값을 직접 쓰지 않는다.** 전부 `mockup.html`의 `:root` 토큰(`var(--sp-4)` 등)을 쓴다.
- 필요한 스타일은 **`mockup.html`에서 복사한다.** 버튼은 `.btn .btn-primary`, 포커스 링은 `outline:2px solid var(--leaf); outline-offset:2px`, 로고는 `.logo` 그대로.
- **목업에 없는 요소가 필요해지면 멈추고 팀장에게 묻는다.** 예외는 아래 "완성 예시"에 값까지 적어둔 단일행 입력(`.tinput`) 하나뿐이다.
- [docs/05-design.md](../05-design.md) §11 금지 항목을 그대로 지킨다. 특히 **장식을 임의로 붙이지 않는다** — 장식 점·도트·그라데이션·배경 패턴 금지.

## 완료 조건

- [ ] `frontend/mockups/mockup-login.html` 1개 파일. `mockup.html`의 `<style>` 안 `:root` 토큰 블록을 그대로 복사해 넣는다
- [ ] 화면 중앙에 로그인 카드 1장: 배경 `var(--bg)`, 카드 `var(--bg-elev)` + `1px var(--border)` + `var(--r-card)` + `var(--sh-card)` 대신 그림자 없음(목업에 `--sh-card` 정의가 아직 없으므로 **그림자 넣지 않는다**)
- [ ] 카드 안: 로고(`.logo`, "Arda"의 첫 글자 강조는 `mockup.html`의 `.logo .seed` 방식 그대로) / 이메일 입력 / 비밀번호 입력 / 로그인 버튼(`.btn .btn-primary`, 카드 폭 100%)
- [ ] **카드만 화면 중앙**에 놓는다. 카드 **안의 텍스트·라벨은 좌측 정렬** (05-design §11: 전부 가운데 정렬 금지)
- [ ] 라벨은 `<label for>`로 입력과 연결. placeholder로 라벨을 대체하지 않는다
- [ ] 상태 전부 (05-design §6): 입력 default / hover / focus-visible / disabled, 버튼 default / hover / press / focus-visible / disabled
- [ ] 빈 값 검증: 이메일·비밀번호가 비면 버튼 비활성. 입력하면 활성 (JS 몇 줄, `mockup.html`의 `#nadd` 토글과 같은 방식)
- [ ] 로그인 실패 문구 자리: 카드 안 버튼 위, 12px `var(--danger)`. 기본은 `hidden`, 화면 확인용으로 주석에 켜는 방법을 적어둔다
- [ ] 어떤 창 크기에서도 겹침·삐져나옴 없음. 가로 스크롤 없음. 모바일 폭(375px)에서 카드가 화면에 들어온다
- [ ] 비밀번호 입력은 `type="password"`, 자동완성 속성 `autocomplete="current-password"` / 이메일은 `autocomplete="username"`

## 완성 예시

단일행 입력은 목업에 없다. **아래를 그대로 복사해 쓴다. 값을 바꾸지 않는다.**

```html
<style>
.tfield{ display:flex; flex-direction:column; gap:var(--sp-2); }
.tfield label{ font-family:var(--sans); font-size:var(--font-sm); font-weight:600; color:var(--text); }
.tinput{ width:100%; height:40px; padding:0 var(--sp-3);
         border:var(--border-w) solid var(--border); border-radius:var(--r-ctl);
         background:var(--bg-elev); font-family:var(--sans); font-size:var(--font-body); color:var(--text);
         transition:border-color var(--dur-fast) var(--ease); }
.tinput::placeholder{ color:var(--text-sub); }
.tinput:hover{ border-color:var(--sunken-hover); }
.tinput:focus-visible{ outline:2px solid var(--leaf); outline-offset:1px; border-color:var(--leaf); }
.tinput:disabled{ background:var(--bg-sunken); color:var(--text-sub); cursor:not-allowed; }
</style>

<div class="tfield">
  <label for="email">이메일</label>
  <input class="tinput" id="email" type="email" autocomplete="username" placeholder="name@company.com">
</div>
```

## Claude에게 시키기

작업 폴더에서 Claude Code를 열고 아래를 붙여넣는다. 한 번에 다 시키지 말고 **1 → 2 → 3 순서로 하나씩** 시킨다. 각 단계가 끝나면 브라우저에서 직접 열어보고 다음으로 넘어간다.

```
1단계.
frontend/mockups/mockup.html 을 읽고, 그 파일의 <style> 안 :root 토큰 블록을 그대로 복사해서
frontend/mockups/mockup-login.html 을 새로 만들어라.
내용은 배경 var(--bg) 위에 화면 중앙 정렬된 빈 카드 하나만. 카드는 var(--bg-elev) 배경 +
1px var(--border) + var(--r-card), 폭 360px, 패딩 var(--sp-6). 그림자 없음.
카드 안에는 아무것도 넣지 마라. 새 색·새 간격 값을 만들지 마라 — 토큰만 쓴다.

2단계.
그 카드 안에 위에서 아래로: 로고(mockup.html의 .logo와 .logo .seed 규격 그대로),
이메일 입력, 비밀번호 입력, 로그인 버튼(mockup.html의 .btn .btn-primary, 폭 100%).
입력은 지시서의 .tfield/.tinput CSS를 그대로 복사해 쓴다 — 값을 바꾸지 마라.
라벨은 <label for>로 연결하고, 카드 안 텍스트는 좌측 정렬.

3단계.
빈 값이면 버튼 비활성, 둘 다 입력되면 활성 (mockup.html의 #nadd 토글과 같은 방식, JS 몇 줄).
그리고 버튼 위에 로그인 실패 문구 자리를 만들어라 — 12px var(--danger), 기본 hidden,
켜보는 방법을 HTML 주석으로 적어라.
```

**주의**: Claude가 스키마 변경, `mockup.html` 수정, 새 색·새 간격 값 추가, 라이브러리 설치를 제안하면 **수락하지 말고** 팀 채널에 물어본다.

## 검증 방법

```bash
python -m http.server 5500 --directory frontend/mockups
```

브라우저에서 `http://localhost:5500/mockup-login.html` 을 열고 확인한다.

기대 결과:

- 입력이 비었을 때 버튼이 회색으로 비활성, 둘 다 채우면 잎초록으로 활성
- Tab 키로 이동할 때 모든 입력·버튼에 초록 포커스 링이 보인다
- 창 폭을 375px까지 줄여도 카드가 화면 안에 있고 가로 스크롤이 생기지 않는다
- 브라우저 개발자도구 콘솔에 에러가 없다
