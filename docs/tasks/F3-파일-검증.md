# [F3] 파일 확장자 · 용량 검증

> 담당: 팀원1 · 역할 C(파일·알림) · 브랜치: `feat/f3-file-validation`
> **PR 단위**: 이 지시서 전체 = PR 1개

## 배경

presigned URL 은 한 번 발급하면 **그 URL 로 무엇이든 올라간다.** 100MB 짜리 동영상도, `.exe` 도 올라간다. S3 요금과 저장소가 그대로 새고, 담당자가 열 수 없는 파일이 이력서 자리에 박힌다.

막을 지점은 **발급 시점**이다. 확장자와 크기가 규격을 벗어나면 애초에 URL 을 주지 않는다.

## 선행 조건 — 없으면 중단

아래가 하나라도 아니면 **시작하지 말고 팀 채널에 알린다.** 없는 것을 상상해서 만들지 않는다.

- [ ] [F1 S3 presigned](F1-S3-presigned.md) PR이 머지돼 있다

## 가장 중요한 규칙

- **[backend/app/models.py](../../backend/app/models.py)를 수정하지 않는다.** 컬럼이 부족해 보여도 추가하지 않는다. 멈추고 팀 채널에 묻는다.
- **[docs/01-erd.md](../01-erd.md)·[docs/02-api.md](../02-api.md)를 수정하지 않는다.** 공용 문서다.
- **인증·권한 코드를 넣지 않는다.** 인증은 팀장 담당(A1~A3)이고 아직 없다. 토큰 검사를 흉내 내면 나중에 팀장 것과 충돌한다. 사용자 id 가 필요한 자리는 `# TODO(A1): 토큰의 사용자로 채운다` 주석만 남긴다.
- **`main.py` 는 `include_router` 한 줄만** 건드린다. 그 파일의 다른 부분은 손대지 않는다.
- **허용 목록(allowlist)으로 막는다.** 금지 목록은 빠지는 게 생긴다.
- **허용 형식은 `pdf` · `docx` · `hwp` · `hwpx` 다** ([01-erd.md](../01-erd.md) `files` 비고에 확정돼 있다). 임의로 늘리지 않는다.

## 완료 조건

- [ ] `backend/app/api/files.py` 의 presign 요청에 `size_bytes: int` 추가
- [ ] 허용 확장자 목록을 **모듈 상수**로 둔다 — 함수 안에 문자열을 흩뿌리지 않는다
- [ ] 허용 밖 확장자 → **422**, 메시지에 허용 목록을 담는다
- [ ] **10MB 초과 → 413**
- [ ] `size_bytes` 가 0 이하 → **422**
- [ ] `content_type` 과 확장자가 어긋나면(예: `.pdf` 인데 `image/png`) **422**
- [ ] presigned URL 발급 시 `ContentLength` 조건을 함께 서명해 **S3 단에서도** 크기를 강제한다

## 완성 예시

**이 형태를 그대로 따른다.**

```python
# backend/app/api/files.py (추가분)
from fastapi import HTTPException, status as http

ALLOWED_EXT = {"pdf", "docx", "hwp", "hwpx"}   # 01-erd.md files 비고에서 확정
ALLOWED_TYPE = {
    "pdf": {"application/pdf"},
    "docx": {"application/vnd.openxmlformats-officedocument.wordprocessingml.document"},
    "hwp": {"application/x-hwp", "application/haansofthwp", "application/octet-stream"},
    "hwpx": {"application/hwp+zip", "application/octet-stream"},
}
MAX_BYTES = 10 * 1024 * 1024   # 10MB


def _validate(ext: str, content_type: str, size_bytes: int) -> None:
    if ext not in ALLOWED_EXT:
        raise HTTPException(
            http.HTTP_422_UNPROCESSABLE_ENTITY,
            f"허용되지 않는 형식입니다. 가능: {', '.join(sorted(ALLOWED_EXT))}",
        )
    if size_bytes <= 0:
        raise HTTPException(http.HTTP_422_UNPROCESSABLE_ENTITY, "파일 크기가 올바르지 않습니다")
    if size_bytes > MAX_BYTES:
        raise HTTPException(http.HTTP_413_REQUEST_ENTITY_TOO_LARGE, "파일은 10MB 이하만 올릴 수 있습니다")
    if content_type not in ALLOWED_TYPE[ext]:
        raise HTTPException(http.HTTP_422_UNPROCESSABLE_ENTITY, "확장자와 파일 형식이 맞지 않습니다")
```

크기는 **S3 단에서도** 막는다. 클라이언트가 보낸 `size_bytes` 는 거짓일 수 있다.

```python
_client.generate_presigned_url(
    "put_object",
    Params={"Bucket": BUCKET, "Key": key, "ContentType": content_type,
            "ContentLength": size_bytes},   # 서명에 포함 → 다른 크기로 올리면 S3 가 거절
    ExpiresIn=300,
)
```

## 검증 방법

```bash
P=localhost:8000/api/v1/public/files/presign-upload
curl -s -o /dev/null -w 'exe %{http_code}\n' -X POST $P -H 'content-type: application/json' -d '{"filename":"a.exe","content_type":"application/pdf","kind":"resume","size_bytes":100}'
curl -s -o /dev/null -w '11MB %{http_code}\n' -X POST $P -H 'content-type: application/json' -d '{"filename":"a.pdf","content_type":"application/pdf","kind":"resume","size_bytes":11534336}'
curl -s -o /dev/null -w '타입불일치 %{http_code}\n' -X POST $P -H 'content-type: application/json' -d '{"filename":"a.pdf","content_type":"image/png","kind":"resume","size_bytes":100}'
curl -s -o /dev/null -w '크기0 %{http_code}\n' -X POST $P -H 'content-type: application/json' -d '{"filename":"a.pdf","content_type":"application/pdf","kind":"resume","size_bytes":0}'
curl -s -o /dev/null -w '정상 %{http_code}\n' -X POST $P -H 'content-type: application/json' -d '{"filename":"a.pdf","content_type":"application/pdf","kind":"resume","size_bytes":1024}'
curl -s -o /dev/null -w 'hwp %{http_code}\n' -X POST $P -H 'content-type: application/json' -d '{"filename":"a.hwp","content_type":"application/octet-stream","kind":"resume","size_bytes":1024}'
```

기대 결과:

- `.exe` → **422**, 메시지에 `pdf, docx, hwp, hwpx` 가 보인다
- 11MB → **413**
- `.pdf` + `image/png` → **422**
- `size_bytes: 0` → **422**
- 정상 pdf → **200**
- `.hwp` → **200** (한글 파일이 막히면 안 된다)
