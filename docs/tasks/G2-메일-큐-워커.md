# [G1·G2·G3] SES 발송 + SQS 워커 · 재시도

> 담당: 팀원1 · 역할 C(파일·알림) · 브랜치: `feat/g2-mail-queue`
> **PR 단위**: 이 지시서 전체 = PR 1개

## 배경

단계를 바꾸는 API 안에서 메일을 직접 보내면 **SES 가 느릴 때 담당자 화면이 같이 멈추고, SES 가 죽으면 단계 변경까지 실패한다.** 칸반에서 카드 하나 끄는 데 3초가 걸리면 아무도 안 쓴다.

단계 변경은 **큐에 넣고 즉시 끝낸다.** 워커가 따로 꺼내서 보낸다. 실패하면 워커만 재시도하고, 상한을 넘으면 `failed` 로 남긴다.

**이 구조가 이 사람의 면접 카드다** — "메일을 왜 비동기로 뺐는가, 실패하면 어떻게 되는가".

## 선행 조건 — 없으면 중단

아래가 하나라도 아니면 **시작하지 말고 팀 채널에 알린다.** 없는 것을 상상해서 만들지 않는다.

- [ ] [docs/01-erd.md](../01-erd.md)가 확정 상태다
- [ ] [J0 앱 뼈대](J0-앱-뼈대.md) PR이 머지돼 있다
- [ ] [G1 메일 템플릿 문구](G1-메일-템플릿-문구.md)가 머지돼 `docs/email-templates.md` 에 문구 4종이 있다
- [ ] **AWS SQS 큐 · SES 발신 도메인 인증이 끝났다** — 없으면 팀장에게 요청한다. SES 샌드박스에서는 인증된 주소로만 발송된다

## 가장 중요한 규칙

- **[backend/app/models.py](../../backend/app/models.py)를 수정하지 않는다.** 컬럼이 부족해 보여도 추가하지 않는다. 멈추고 팀 채널에 묻는다.
- **[docs/01-erd.md](../01-erd.md)·[docs/02-api.md](../02-api.md)를 수정하지 않는다.** 공용 문서다.
- **인증·권한 코드를 넣지 않는다.** 인증은 팀장 담당(A1~A3)이고 아직 없다. 토큰 검사를 흉내 내면 나중에 팀장 것과 충돌한다. 사용자 id 가 필요한 자리는 `# TODO(A1): 토큰의 사용자로 채운다` 주석만 남긴다.
- **`main.py` 는 `include_router` 한 줄만** 건드린다. 그 파일의 다른 부분은 손대지 않는다.
- **단계 변경 로직(D3)은 팀장 담당이다.** 이 지시서는 "큐에 넣는 함수"와 "워커"만 만든다. 팀장이 그 함수를 호출한다.
- **메일 본문을 코드에 쓰지 않는다.** `docs/email-templates.md` 의 문구를 그대로 쓴다.
- **재시도 상한을 넘으면 조용히 버리지 않는다.** `email_logs.status="failed"` 로 남겨 나중에 셀 수 있게 한다.

## 완료 조건

- [ ] `uv add boto3` (F1 에서 이미 들어갔으면 생략)
- [ ] `backend/app/mail.py` — `enqueue(application_id, stage)` : `email_logs` 행 생성(`status="queued"`) + SQS 발행. **여기서 SES 를 호출하지 않는다**
- [ ] `backend/app/worker.py` — SQS 를 폴링해 SES 로 보내고 `status` 를 `sent` 로 갱신
- [ ] 실패 시 `retry_count += 1` 후 큐로 되돌린다. **3회 초과 → `status="failed"`**
- [ ] **같은 `email_logs.id` 를 두 번 처리해도 메일이 두 번 가지 않는다** — 이미 `sent` 면 건너뛴다 (멱등)
- [ ] 단계별 문구는 `docs/email-templates.md` 4종을 읽어 매핑
- [ ] `backend/.env.example` 에 `SQS_QUEUE_URL` · `SES_FROM_EMAIL` **이름만** 추가
- [ ] 워커는 `python -m app.worker` 로 뜬다 ([J1 compose](J1-docker-compose.md)의 주석 자리와 맞춘다)

## 완성 예시

**이 형태를 그대로 따른다.**

```python
# backend/app/mail.py
"""단계 변경 → 큐. 여기서 SES 를 호출하지 않는다."""
import json
import os

import boto3

from app.models import EmailLog

_sqs = boto3.client("sqs", region_name=os.getenv("AWS_REGION", "ap-northeast-2"))
QUEUE_URL = os.getenv("SQS_QUEUE_URL", "")


def enqueue(db, application_id: int, to_email: str, stage: str) -> EmailLog:
    log = EmailLog(application_id=application_id, to_email=to_email,
                   stage=stage, status="queued", retry_count=0)
    db.add(log)
    db.flush()                      # id 가 있어야 큐에 실어 보낸다
    _sqs.send_message(QueueUrl=QUEUE_URL,
                      MessageBody=json.dumps({"email_log_id": log.id}))
    return log
```

```python
# backend/app/worker.py (핵심만)
MAX_RETRY = 3

def handle(db, email_log_id: int) -> None:
    log = db.get(EmailLog, email_log_id)
    if log is None or log.status == "sent":
        return                       # 멱등 — 같은 메시지를 두 번 받아도 두 번 보내지 않는다
    try:
        send_via_ses(log.to_email, *render(log.stage))
        log.status, log.sent_at = "sent", func.now()
    except Exception:
        log.retry_count += 1
        # 상한을 넘으면 조용히 버리지 않는다. 나중에 셀 수 있게 failed 로 남긴다
        log.status = "failed" if log.retry_count > MAX_RETRY else "queued"
        if log.status == "queued":
            raise                    # 예외를 다시 던져 SQS 가 재전달하게 둔다
    finally:
        db.commit()
```

## 검증 방법

```bash
cd backend && uv run python -m app.worker &
uv run python -c "
from app.db import SessionLocal
from app.mail import enqueue
db = SessionLocal()
log = enqueue(db, application_id=1, to_email='본인주소@example.com', stage='screening')
db.commit(); print('queued id =', log.id)
"
sleep 10
psql "$DATABASE_URL" -c "select id, stage, status, retry_count, sent_at from email_logs order by id desc limit 5"
git grep -nE 'AKIA|aws_secret' -- backend/ || echo '시크릿 미노출 OK'
```

기대 결과:

- `enqueue` 직후 `email_logs` 에 `status=queued` 행이 생긴다
- 워커가 처리한 뒤 **`status=sent`** 로 바뀌고 `sent_at` 이 찍힌다
- **메일이 실제로 도착한다** (SES 샌드박스면 인증된 주소로)
- 큐 URL 을 일부러 틀리게 하면 `retry_count` 가 올라가고, 4번째에 **`status=failed`**
- 같은 메시지를 두 번 넣어도 메일은 **한 번만** 온다
- `git grep` 에 AWS 키가 안 나온다
