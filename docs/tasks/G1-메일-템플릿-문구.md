# [G1] 단계별 메일 템플릿 문구 4종

> 담당: (이름) · 브랜치: `feat/g1-email-templates`

## 배경

지원자가 단계를 이동하면 자동으로 메일이 발송된다(G1). 발송 시스템은 다른 사람이 만들지만, **무엇을 보낼지(문구)**가 먼저 있어야 한다. 회사가 실제로 보내도 어색하지 않은 수준의 한국어 문구가 목표다.

## 완료 조건

- [ ] `docs/email-templates.md`에 템플릿 4종: ① 서류 합격(면접 안내 포함) ② 면접 결과 합격 ③ 최종 합격 ④ 불합격
- [ ] 각 템플릿에 제목 + 본문, 변수는 `{{지원자명}}` `{{공고명}}` `{{회사명}}` `{{면접일시}}` 형식으로 표기
- [ ] 불합격 문구는 정중하고 담백하게 — 과한 위로·사족 금지
- [ ] 전 템플릿 존댓말·톤 통일, 이모지·느낌표 남발 금지

```

채용 지원자에게 보내는 공식 메일이니 회사가 실제 발송해도 어색하지 않은 한국어로.
```
