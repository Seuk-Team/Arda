# [A2·G4] 설정 화면 (정적 목업)

> 담당: (이름) · 브랜치: `feat/a2-settings-mockup`
> **PR 단위**: 이 지시서 전체 = PR 1개

## 배경

사이드바 "설정" 화면. 탭 3개로 나뉜다 — **내 계정 / 사용자·권한(관리자) / 메일 템플릿**([05-design](../05-design.md) §0.5). 사이드바 하단 프로필을 눌러도 여기 "내 계정" 탭으로 들어온다.

정적 목업이라 탭 전환만 동작하면 되고, 저장·API는 범위 밖이다.

## 시작 전에 읽는다

- [ ] [docs/05-design.md](../05-design.md) **전체를 한 번 읽는다**
- [ ] [CLAUDE.md](../../CLAUDE.md)의 "범위" 항목
- [ ] [frontend/mockups/mockup.html](../../frontend/mockups/mockup.html)을 브라우저로 열어 **눈으로 본다**

## 선행 조건 — 없으면 중단

- [ ] `main`에 `mockup.html`이 있고 브라우저에서 열린다
- [ ] **A1 로그인 화면 PR이 머지돼 있다** — 입력 컴포넌트(`.tfield` `.tinput`)를 거기서 복사해 온다. 아직이면 기다린다
- [ ] 직전 UI 작업 PR이 머지돼 있다

## 가장 중요한 규칙 — 새로 만들지 않는다

- 값은 전부 `:root` 토큰으로.
- 복사해 쓸 것: `.sidebar` `.nav` `.me` / `.head` `.title` / `.tpanel` `.trow` `.thead` `.trow-item` / `.btn` `.btn-primary` / `.ninput`(메일 본문 편집) / **`mockup-login.html`의 `.tfield` `.tinput`**
- 새로 만드는 것은 **탭(`.tabs`) 하나뿐**이다. 아래 완성 예시를 그대로 쓴다.
- 목업에 없는 요소가 필요해지면 **멈추고 팀장에게 묻는다.**

## 완료 조건

- [ ] `frontend/mockups/mockup-settings.html` 1개 파일. `:root` 토큰 블록 + 필요한 클래스 복사
- [ ] 사이드바 `.active`를 "설정"으로 옮긴다
- [ ] 헤더: 제목 "설정". 뒤로 가기·우측 버튼 없음
- [ ] 탭 3개: **내 계정 / 사용자·권한 / 메일 템플릿**. 클릭하면 아래 내용이 바뀐다(JS 몇 줄). 새로고침 시 첫 탭
- [ ] **내 계정 탭**: 이름 / 이메일 / 역할(읽기 전용, `.tinput:disabled`) 입력 3개 + "저장" 버튼(`.btn .btn-primary`). 입력은 `.tfield` `.tinput` 복사
- [ ] **사용자·권한 탭**: 테이블 컬럼 4개 — 이름 / 이메일 / 역할 / 상태. 행 5개. 역할은 관리자·채용담당자·면접관이 섞이게. 우측 상단에 "사용자 추가" 버튼
- [ ] **메일 템플릿 탭**: 왼쪽에 단계 4종 목록(서류 검토 / 면접 / 최종 합격 / 불합격), 오른쪽에 제목 입력(`.tinput`) + 본문 입력(`.ninput` 복사) + "저장" 버튼
- [ ] 탭 상태 전부 (05-design §6): default / hover / press / focus-visible / 선택됨
- [ ] 탭은 키보드로 이동 가능(Tab). 선택된 탭은 `aria-selected="true"`
- [ ] 가로 스크롤 없음, 겹침 없음. 창 폭을 줄이면 메일 템플릿 탭의 좌우가 세로로 쌓인다

## 완성 예시

탭은 목업에 없다. **아래를 그대로 복사해 쓴다. 값을 바꾸지 않는다.**

```html
<style>
.tabs{ display:flex; gap:var(--sp-2); border-bottom:var(--border-w) solid var(--border);
       margin-bottom:var(--sp-5); }
.tabs button{ height:44px; padding:0 var(--sp-4); border:none; background:none; cursor:pointer;
              font-family:var(--sans); font-size:var(--font-body); font-weight:600; color:var(--text-sub);
              white-space:nowrap; border-bottom:2px solid transparent; margin-bottom:-1px;
              transition:color var(--dur-fast) var(--ease), background var(--dur-fast) var(--ease); }
.tabs button:hover{ color:var(--text); background:var(--bg-sunken); }
.tabs button:active{ background:var(--bg-elev); }
.tabs button:focus-visible{ outline:2px solid var(--leaf); outline-offset:-2px; }
.tabs button[aria-selected="true"]{ color:var(--leaf); border-bottom-color:var(--leaf); }
</style>

<div class="tabs" role="tablist">
  <button role="tab" aria-selected="true">내 계정</button>
  <button role="tab" aria-selected="false">사용자·권한</button>
  <button role="tab" aria-selected="false">메일 템플릿</button>
</div>
```

탭 높이 44px은 터치 타깃 최소 규격이다(05-design §9). **줄이지 마라.**

## 검증 방법

```bash
python -m http.server 5500 --directory frontend/mockups
```

`http://localhost:5500/mockup-settings.html`

기대 결과:

- **`mockup.html`과 `mockup-login.html`을 옆 탭에 함께 띄우고 나란히 비교한다.** 색·간격·글자 크기·모서리 반경·그림자가 눈으로 구분되지 않는다. 목업에 없는 요소를 새로 만들지 않았다
- 탭 3개가 눌리고, 선택된 탭만 잎초록 밑줄이 붙는다
- Tab 키로 탭·입력·버튼에 초록 포커스 링이 보인다
- 역할 입력이 비활성으로 보인다(회색 배경, 커서 금지 표시)
- 창 폭을 줄여도 가로 스크롤·겹침이 없다
- 콘솔에 에러가 없다

## 막히면 · 되돌리기

- **30분 넘게 막히면 혼자 붙들지 말고 팀 채널에 묻는다.** 혼자 Claude와 씨름한 2시간이, 팀장이 5분에 답할 것을 이상한 결과물로 바꿔놓는다.
- **결과가 이상해지면 고치려 들지 말고 버린다.** 코드를 읽어 고치는 것보다 되돌리는 편이 빠르고 안전하다.

```bash
git checkout -- .
```

그래도 이상하면 브랜치째 버리고 처음부터 다시 시작한다.

```bash
git checkout main && git branch -D <브랜치명>
```

- **`git status`에 지시서에 없는 파일이 떠 있으면 Claude가 범위를 벗어난 것이다.** 그 변경은 되돌리고 팀 채널에 알린다.
